# Sécurité / Security

La démonstration statique n’exécute aucune commande serveur. Le runtime
Community inclus utilise un agent privilégié et doit rester sur
un hôte privé de confiance. Ne publier ni socket Docker ni port agent.

Signaler une vulnérabilité en privé à contact@hugoviaud.fr avec version, contexte
et étapes reproductibles expurgées. Ne joindre aucun secret, monde, nom de joueur
ou donnée client. Ne publier pas d’exploit ou d’informations sensibles dans une
issue publique avant coordination. Aucun délai de réponse contractuel.

Report vulnerabilities privately to contact@hugoviaud.fr with the version and
redacted reproduction steps. Do not attach credentials, worlds or personal data.
The runtime is a candidate; real Minecraft Java restore compatibility
remains unverified. No contractual response time is promised.
