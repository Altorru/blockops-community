GUIDE / CONSOLE LOCALE

Sauvegarder votre monde. Vérifier le retour.

BlockOps est un candidat gratuit pour superviser un seul serveur Minecraft Java Docker et gérer ses sauvegardes locales. La console s’installe chez vous. Cette page présente son fonctionnement ; elle n’exécute aucune commande.

La recette actuelle utilise un Docker Engine simulé et un statut Java synthétique. La compatibilité avec un vrai serveur Java reste à vérifier sur une cible jetable autorisée. Aucun service cloud ni achat disponible.

Le parcours de sauvegarde et de restauration

  1. Préparer un test isolé. Utiliser un conteneur et un monde jetables autorisés, avec une copie indépendante. Garder l’agent privé et la console sur localhost ou un tunnel SSH. L’EULA doit avoir été acceptée par le propriétaire.
  2. Créer une copie. Le serveur est arrêté pendant la sauvegarde ; les joueurs sont déconnectés. Un arrêt non confirmé ou un kill forcé entraîne un refus de sauvegarde. Inspecter les logs avant de reprendre.
  3. Restaurer sur le monde de test. Arrêter volontairement, confirmer la restauration et contrôler la copie de sécurité. Le serveur reste arrêté après la restauration.
  4. Vérifier tous les fichiers. Comparer leurs empreintes à l’archive avant de redémarrer, puis vérifier le statut Java et les logs. Ne jamais modifier level.dat ou un fichier de région comme du texte.

Les copies sont locales et non chiffrées. Une panne de l’hôte peut perdre le monde et ses sauvegardes : conserver une copie indépendante. Prévoir l’espace pour l’archive, l’extraction, la copie de sécurité et le rollback.

Paquet Community gratuit remis en privé : logiciel, guide d’installation, fixture sans Minecraft, préflight de cible et contrôle des fichiers restaurés, avec empreinte SHA-256. Les cinq places sont un objectif de test, pas une preuve de compatibilité.

Questions fréquentes

Est-ce une console Minecraft accessible sur ce site ?

Non. Le site est une vitrine et un guide. La console et son agent restent sur votre hôte privé.

Est-ce compatible avec mon serveur ?

La cible est Minecraft Java dans Docker. La validation sur un vrai serveur reste en attente ; aucune compatibilité Bedrock, modpack ou plugin n’est annoncée.

Combien coûte BlockOps ?

Le self-hosted est gratuit sous MIT. Votre hôte, stockage et maintenance restent à votre charge. L’offre cloud est une hypothèse, sans paiement disponible.

Puis-je essayer sans risquer mon monde ?

Commencer avec la fixture sans Minecraft, puis une copie de test autorisée. La fixture démontre les opérations de fichiers ; elle ne prouve pas une sauvegarde Minecraft réelle.
